# Dashboard
[17:46, 01/02/2026] Leandro: # Dashboard por Horário

## 📌 Descrição
Projeto FRONT-END desenvolvido para demonstrar minhas habilidades em HTML, CSS e JavaScript puro.
O dashboard altera conteúdo visual e textual com base no horário atual do dia.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Mobile First + Grid Layout)
- JavaScript (Vanilla)

## 🚀 Funcionalidades
- Identificação automática do período do dia
- Alteração dinâmica de texto, imagem e estilo
- Layout responsivo (mobile first)
- Interface simples e intuitiva

## 🧠 Objetivo do Projeto
Praticar manipulação de DOM, eventos e lógica condicional em JavaScript, além de reforçar conceitos de responsividade e organização de código.
